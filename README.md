# DMLCOMMAND
Managers Database

# Project Overview

This project involves the creation of a Managers table in an SQL database, inserting data, and executing various queries to retrieve specific records. The table consists of fields such as Manager_Id, First_name, Last_Name, DOB, Age, Last_update, Gender, Department, and Salary with constraints to ensure data integrity.

# Table Creation

The Managers table is created using the following schema:

Manager_Id (Primary Key) – Unique identifier for each manager.

First_name – Manager’s first name.

Last_Name – Manager’s last name.

DOB (Date of Birth) – Date format (YYYY-MM-DD).

Age – Ensures managers are at least 18 years old using a CHECK constraint.

Last_update – Automatically stores the last modification time.

Gender – Limited to 'M' or 'F'.

Department – Specifies the department the manager belongs to.

Salary – Ensures salary is NOT NULL.
